출처: 메리츠화재 「보험료납입지원 특별약관」 보험료 및 책임준비금 산출방법서
(`0. 보험료 산출 방법서/보험료납입지원(메리츠)/003_보험료납입지원 특별약관_산출방법서.pdf`, DRM 없음)

이 특약은 **여러 상품에 그대로 붙일 수 있는 납입면제 장치**다. 이 앱에서 어떻게 쓰는지까지 함께 적는다.

## 1. 담보 한 줄 요약

| 항목 | 내용 |
|---|---|
| 담보명 | 보험료납입지원(고도후유장해 및 3대질병진단)보장 |
| 지급사유 | 고도후유장해(후유장해 80% 이상) **또는** 3대질병(암·뇌졸중·급성심근경색증) 진단 |
| 지급형태 | 남은 보험료를 **매월지급액 × 지급약정기간(월)** 로 대신 낸다 (일시금 전환식 별도) |
| 가입나이 | 15세 이상 |
| 예시 계약 | 20년만기 20년납 (선택계약, 영업보험료 기준 α₁·α₂·β·γ) |
| 적용이율 | 연 3.25% (적립부분은 공시이율, **최저보증이율 1.0%**) |
| 손해조사비 | 매년 영업보험료의 **1%** (ce) |
| 책임준비금 | 적용기초율 기준과 표준기초율 기준 중 **큰 값**. 표준은 표준이율의 125% |

## 2. 위험률 (지급사유 = 탈퇴사유)

산출방법서의 "2. 탈퇴율에 관한 사항"은 이 담보의 탈퇴율을 아래의 **합**으로 둔다.

- 일반상해 후유장해발생률(80% 이상) — 1급·2급·3급 구분 (예: 남자 0.000048 / 0.000129 / 0.000157)
- 질병 후유장해발생률(80% 이상)
- 암발생률
- 뇌졸중발생률
- 급성심근경색증발생률

한 번 지급하면 그 담보가 끝나므로 **급부 = 탈퇴**인 진단형이다.

## 3. 지급보험금 (일시금 환산)

> [납입방법별 순보험료 × k′ − {보험년도 연말 순보험료식 보험료적립금 ÷ (1 + 적용이율)
> − 보험년도 연시 순보험료식 보험료적립금}] ÷ 12

`k′` = 연납 1 · 6개월납 2 · 3개월납 4 · 월납 12.
즉 **남은 기간의 순보험료 현가**에서 적립금 증가분을 뺀 값이 그 해에 지원할 금액이다.

## 4. 이 앱에서 쓰는 법

이 앱의 산출기는 **납입자 집단 l′** 로 납입면제를 다룬다(`lib/engine/commutation.ts`).

```
l′_{t+1} = l′_t · (1 − q − f − w + (qf + qw + fw)/2)
```

`f` 가 이 특약의 지급사유 발생률이다. `f` 가 크면 납입자가 빨리 줄어 **N′ 가 작아지고, P = PVB / N\* 가 올라간다** —
"면제해 주는 값"이 주계약 보험료에 얹히는 것이며, 위 3.의 일시금을 따로 계산하는 방식과 뜻이 같다.

### 붙이는 순서 (설계 화면 `/builder`)

1. **M04 위험률 표**에서 열을 추가하고 프리셋 **"납입면제 발생률 (고도후유장해 + 3대질병)"** 을 고른다
   (`waiverSupport` — `lib/plan-rates.ts`). 열의 **납입면제** 체크가 자동으로 켜진다.
2. **M05 납입면제** 단계에서 납입면제를 **적용**으로 둔다 (탭마다 주계약에서 상속).
3. 여러 열에 납입면제를 켜면 **합산**해 `f` 로 쓴다 (`waiverCols` → `sumColumns`).
4. 특약 탭에서 다르게 두려면 그 탭의 납입면제만 끄면 된다 — "주계약과 다름"으로 표시된다.

빠른 시작은 레시피 **"납입면제(보험료납입지원) 적용 3대질병"** 을 고르면 1~2가 이미 되어 있다.

### 위험률 대체

| 방법서 항목 | 이 앱에서 쓰는 값 | 비고 |
|---|---|---|
| 후유장해발생률(80% 이상) | 제7회 경험생명표 장해 50% 이상 발생률 `f` | **더 넓다** — 보험료가 조금 크게 나온다 |
| 암발생률 | 생명장기제2024-112호 무배당 예정 암발생률 | 실제 값 |
| 뇌졸중발생률 | 제공받은 뇌출혈 발생률 (0~84세) | 뇌졸중 ⊃ 뇌출혈이라 조금 좁다 |
| 급성심근경색증발생률 | 제공받은 급성심근경색증 발생률 (0~79세) | 실제 값 |

회사 요율을 받으면 M04 표에 붙여넣거나 엑셀로 올려 그대로 바꿔 쓰면 된다.

## 5. 아직 하지 않은 것

- **특약 자체의 보험료**(3.의 일시금을 급부로 보는 독립 담보 산출)는 넣지 않았다.
  보장금액이 "그 시점의 남은 보험료"라 주계약 보험료와 서로를 참조하는 순환이 생긴다.
  필요해지면 `computePlan` 을 두 번 돌려(면제 없는 보험료로 급부표를 만든 뒤 다시 산출) 풀면 된다.
- 1급·2급·3급 장해 등급별 지급률 구분은 넣지 않았다(합산 하나로 본다).
