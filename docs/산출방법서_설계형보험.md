# 보험료 및 책임준비금 산출방법서

**설계형 종신보험(무배당) · 설계형 암보험(무배당)**

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-09-19 |
| 대상 | 설계형 종신보험(무배당), 설계형 암보험(무배당) 및 부가 특약 |
| 종류 | 1종 표준형(완전 환급) · 2종 저해지환급형(70%) · 3종 무해지환급형 |
| 산출 단위 | 기준보험금 1단위(배수 1.0) 기준, 라딕스 *l<sub>x</sub>* = 100,000 |
| 근거 코드 | `lib/engine/` (commutation · premium · reserve · surrender · compute · riders · plan) |

이 문서는 앱이 실제로 수행하는 계산을 산출방법서 형식으로 옮긴 것이다. 각 절 끝의 *(코드)* 표시는 해당 산식이 구현된 파일이며, 문서와 코드가 어긋나면 코드가 기준이다. 부록 B의 수치는 회귀 테스트로 고정되어 있다.

이 상품은 계약자가 **연령별 보험금 배수를 직접 정한다**는 점에서 일반 상품과 다르다. 따라서 급부가 상수가 아니라 연도별 수열 *S<sub>t</sub>* · *C<sub>t</sub>* 로 주어지며, 모든 산식이 이 수열의 합 형태로 표현된다.

---

## 1. 기초율에 관한 사항

### 1.1. 이율(*i*)에 관한 사항

**가. 적용이율**

| 상품 | 가정 세트 | 연복리 |
|---|---|---|
| 설계형 종신보험 | `default-2026` | 2.5% |
| 설계형 암보험 | `cancer-2026` | 3.25% |
| (검증용) | `verify-term-1504` | 3.4% |

**나. 표준이율**

연복리 3.25%. 표준책임준비금과 해약공제 기준 신계약비 산출에만 쓴다.

*v* = 1 / (1 + *i*) 로 하고, 표준기초율 계산에는 표준이율로 구한 *v*<sub>std</sub> 를 쓴다.

적용이율·표준이율은 설정 화면에서 바꿀 수 있으며, 바꾸면 가정 세트가 "사용자 정의"가 된다. *(코드: `lib/engine/data/assumptions.json`, `app/settings/page.tsx`)*

### 1.2. 위험률에 관한 사항

**가. 적용위험률**

(1) **설계형 종신보험**

- 무배당 예정 경험사망률 *q<sub>x</sub>* : 제7회 경험생명표
- 무배당 예정 납입면제(장해 50% 이상) 발생률 *f<sub>x</sub>*

사망과 장해의 이중탈퇴로 산출한다. 급부(사망보험금)는 사망집단 *l<sub>x</sub>* 기준, 보험료 납입은 납입집단 *l′<sub>x</sub>* 기준이다.

(2) **설계형 암보험**

- 무배당 예정 암발생률 *q<sub>x</sub>* : 생명장기제2024-112호(2024.01.15)

암 진단 시 암진단보험금을 지급하고 그 계약은 소멸한다. **사망 시에는 책임준비금을 지급**하므로 사망은 급부 현가와 준비금에 순효과가 없고, 따라서 암발생률만을 탈퇴율로 쓰는 **단일탈퇴**로 산출한다. 납입면제는 적용하지 않는다.

(3) **특약**

특약마다 소멸사유 탈퇴율 *q*<sup>exit</sup> 와 급부 발생률 *q*<sup>event</sup> 를 따로 둔다. 상세는 2.6절.

**나. 표준위험률**

보험업감독규정 제6-12조 제1항 제2호 및 같은 규정 시행세칙 제4-4조 제3항 제1호에 의한 표준위험률(*q*<sup>std</sup><sub>x</sub>, *f*<sup>std</sup><sub>x</sub>)을 사용하며, 표준위험률이 없는 경우에는 "가. 적용위험률"에서 정한 위험률을 사용한다.

> 일반 상품 산출기(6절, `/builder`)는 담보별 표준위험률을 따로 받지 않으므로 항상 이 단서에 따라 적용위험률을 쓴다. 표준기초율 계산에서 달라지는 것은 이율뿐이다.

**다. 최종연령 *ω***

| 보장 | 남 | 여 |
|---|---|---|
| 사망보장(종신) | 110세 | 112세 |
| 사망 외 보장(암 주계약 및 모든 특약) | 100세 만기 | 100세 만기 |

보장기간 *n* = *ω* − *x* 로 하고, 사망보장은 *t* = 0 … *n*−1, 생존급부는 *t* = 0 … *n* 으로 색인한다.

### 1.3. 적용해지율(*w<sub>x</sub>*)에 관한 사항

| 종류 | 적용해지율 |
|---|---|
| 1종 표준형(완전 환급) | 연 0% |
| 2종 저해지환급형 · 3종 무해지환급형 | 연 3.0% (단, 보험료 납입기간 완료 후에는 "0%") |

적용해지율은 저해지·무해지환급형의 보험료·책임준비금·해지환급금 산출에만 쓴다. 표준형은 *w* = 0 이므로 1.2절의 이중탈퇴 산식과 완전히 같아진다. *(코드: `lib/engine/types.ts` `Basis.lapse`)*

### 1.4. 면책기간에 관한 사항

암 관련 보장은 계약일부터 90일의 면책기간을 둔다. 면책계수 *r*<sub>wait</sub> = 3/4 를 **첫해 급부에만** 곱하여 산출한다(표시용 보험금은 그대로 둔다).

*S*<sup>산출</sup><sub>0</sub> = *r*<sub>wait</sub> · *S*<sub>0</sub>,  *S*<sup>산출</sup><sub>t</sub> = *S*<sub>t</sub> (*t* ≥ 1)

일반 상품 산출기에서는 면책기간을 개월 수로 받아 *r*<sub>wait</sub> = 1 − (면책개월)/12 로 한다. *(코드: `lib/engine/compute.ts`, `lib/plan-state.ts` `waitFactorOf`)*

### 1.5. 시산보험료 계산 시 적용하는 사업비에 관한 사항

**가. 산출방법서형(기본)**

| 구분 | 기호 | 기준 | 설계형 종신 | 설계형 암 |
|---|---|---|---|---|
| 계약체결비용 | *α<sub>S</sub>* | 기준보험금 | 1.0/1,000 | 0.5/1,000 |
| 계약체결비용 | *α<sub>P</sub>* | 기준연납순보험료 | 1.00배 | 1.00배 |
| 계약관리비용(납입중, 정액) | *β<sub>S</sub>* | 기준보험금(연) | 1.5/1,000 | 1.2/1,000 |
| 계약관리비용(납입중, 비율) | *β<sub>G</sub>* | 영업보험료 | 4.5% | 7.0% |
| 계약관리비용(납입후, 정액) | *β′* | 기준보험금(연) | 1.0/1,000 | 1.0/1,000 |
| 수금비용 | *γ* | 영업보험료 | 2.5% | 4.0% |

보장기간 *n* 이 20년보다 짧으면 *α<sub>P</sub>* 는 *α<sub>P</sub>* × *n*/20 로 줄인다. *(코드: `lib/engine/compute.ts` `scaleAlphaP`)*

**나. 3이원 단순형(선택)**

*α*(신계약비, 기준보험금 비례), *β*(유지비, 기준보험금 비례·연), *γ*(수금비율)의 3이원만 쓴다.

## 2. 보험료의 계산에 관한 사항

### 2.1. 계산기수

*x* 를 가입나이, *t* 를 경과년, *w<sub>t</sub>* 를 1.3절의 적용해지율(납입기간 *m* 안에서만 0이 아님)이라 할 때

**가. 생존자 수**

*l<sub>x</sub>* = *l′<sub>x</sub>* = 100,000

*l<sub>x+t+1</sub>* = *l<sub>x+t</sub>* · ( 1 − *q<sub>x+t</sub>* − *w<sub>x+t</sub>* + *q<sub>x+t</sub>* · *w<sub>x+t</sub>* / 2 )

*l′<sub>x+t+1</sub>* = *l′<sub>x+t</sub>* · ( 1 − *q<sub>x+t</sub>* − *f<sub>x+t</sub>* − *w<sub>x+t</sub>* + ( *q<sub>x+t</sub>f<sub>x+t</sub>* + *q<sub>x+t</sub>w<sub>x+t</sub>* + *f<sub>x+t</sub>w<sub>x+t</sub>* ) / 2 )

*l* 은 급부집단(사망·발생·해지로 탈퇴), *l′* 은 납입집단(여기에 납입면제 탈퇴를 더함)이다.

**나. 계산기수**

| 기호 | 정의 | 비고 |
|---|---|---|
| *D<sub>x+t</sub>* | *l<sub>x+t</sub>* · *v*<sup>*t*</sup> | 생존급부·준비금 분모 |
| *D′<sub>x+t</sub>* | *l′<sub>x+t</sub>* · *v*<sup>*t*</sup> | 납입기수 |
| *C<sub>x+t</sub>* | *l<sub>x+t</sub>* · *q*<sup>event</sup><sub>*x+t*</sub> · ( 1 − *w<sub>x+t</sub>* / 2 ) · *v*<sup>*t*+½</sup> | 연중앙 발생 |
| *W<sub>x+t</sub>* | *l<sub>x+t</sub>* · *w<sub>x+t</sub>* · *v*<sup>*t*+½</sup> | 연중앙 해지 |
| *N<sub>x+t</sub>* | Σ<sub>*u* ≥ *t*</sub> *D<sub>x+u</sub>* | |
| *N′<sub>x+t</sub>* | Σ<sub>*u* ≥ *t*</sub> *D′<sub>x+u</sub>* | |

*q*<sup>event</sup> 는 급부 발생률로, 사망보장처럼 탈퇴 = 급부인 경우에는 *q* 와 같다. 진단형처럼 탈퇴율이 사망률 + 발생률인 경우에만 둘이 다르다.

*q* · (1 − *w*/2) + *w* = *q* + *w* − *q*·*w*/2 이므로, 발생 탈퇴와 해지 탈퇴의 합이 *l<sub>x+t</sub>* − *l<sub>x+t+1</sub>* 과 정확히 일치한다.

합산 기수 *N* · *N′* 는 *t* = *n* 에서 잘라도 모든 사용처가 차분 형태이므로 원식과 같다. *(코드: `lib/engine/commutation.ts`)*

### 2.2. 보장 스케줄(급부의 정의)

계약자가 정한 연령 구간 카드를 연 단위 수열로 편다.

- *S<sub>t</sub>* : *t*년차 사망보험금(암보험은 암진단보험금) 배수, *t* = 0 … *n*−1. 뒤 카드가 앞 카드를 덮는다.
- *C<sub>t</sub>* : *t*시점 생존급부(축하금) 배수, *t* = 0 … *n*. 같은 시점의 카드는 더한다.

보험금(원) = 배수 × 기준보험금 *S*<sub>0</sub>. *(코드: `lib/engine/schedule.ts` `expandBlocks`)*

### 2.3. 순보험료

**가. 급부 현가**

PVB = Σ<sub>*t*=0</sub><sup>*n*−1</sup> *S*<sup>산출</sup><sub>*t*</sub> · *C<sub>x+t</sub>* + Σ<sub>*t*=0</sub><sup>*n*</sup> *C<sub>t</sub>* · *D<sub>x+t</sub>*

**나. 월납 보정 납입기수**

*N*\* = *mm* · [ ( *N′<sub>x</sub>* − *N′<sub>x+m</sub>* ) − ( *mm* − 1 ) / ( 2 · *mm* ) · ( *D′<sub>x</sub>* − *D′<sub>x+m</sub>* ) ]

*m* : 보험료 납입기간(년), *mm* : 연 납입 횟수(월납 12).

**다. 순보험료**

<sub>*m*</sub>*P*<sup>(*mm*)</sup><sub>*x*</sub> = PVB / *N*\*

**라. 기준연납순보험료**

*P*<sub>base</sub> = PVB / ( *N′<sub>x</sub>* − *N′<sub>x+min(n,20)</sub>* )

신계약비 *α<sub>P</sub>* 의 기준이 되는 값이다. *(코드: `lib/engine/premium.ts`)*

### 2.4. 영업보험료

*G* = [ *P* + ( *α<sub>S</sub>* + *α<sub>P</sub>* · *P*<sub>base</sub> ) · *D′<sub>x</sub>* / *N*\* + *β<sub>S</sub>* / *mm* + *β′* · ( *N<sub>x+m</sub>* − *N<sub>x+n</sub>* ) / *N*\* ] / ( 1 − *β<sub>G</sub>* − *γ* )

3이원 단순형이면

*G* = [ *P* + *α* · *D′<sub>x</sub>* / *N*\* + *β* · ( *N<sub>x</sub>* − *N<sub>x+n</sub>* ) / *N*\* ] / ( 1 − *γ* )

**해약공제 기준 신계약비**

*α* = *α<sub>S</sub>* + *α<sub>P</sub>* · round<sub>5</sub>( *P*<sub>base</sub> )   (round<sub>5</sub> : 소수 5자리 반올림)

적용기초율로 구한 *α* 와 표준기초율로 구한 *α*<sup>std</sup> 중 **작은 쪽**을 해약공제 기준으로 한다(4.1절).

**표시 단위**

보험금 10만원당 보험료(원) = round( 1단위당 보험료 × 100,000 ). 가입금액 기준 보험료 = 10만원당 보험료 × ( *S*<sub>0</sub> / 100,000 ). 반올림을 10만원당에서 한 번만 하여 예산 역산과 표시가 정확히 맞게 한다.

### 2.5. 저해지환급형 · 무해지환급형

환급률 *w<sup>r</sup>* 는 2종(저해지) 70%, 3종(무해지) 0%로 한다.

**가. 해지급부 현가**

CSV<sub>*t*</sub> = Σ<sub>*u* ≥ *t*</sub> *W<sub>x+u</sub>* · *w<sup>r</sup>* · ( <sub>*u*</sub>*W*<sup>표준형</sup><sub>*x*</sub> + <sub>*u*+1</sub>*W*<sup>표준형</sup><sub>*x*</sub> ) / 2   (*u* < *m*)

CSV<sub>*t*</sub> = 0   (*t* ≥ *m*)

<sub>*u*</sub>*W*<sup>표준형</sup><sub>*x*</sub> 는 4.2절의 표준형(1종) 해지환급금이다(1단위당). 해지는 연중앙에 일어나는 것으로 보아 전후 연도 환급금의 평균을 쓴다.

**나. 급부 현가**

Ā<sub>*x*</sub> = PVB + CSV<sub>0</sub>

**다. 보험료**

2.3 · 2.4절의 PVB 자리에 Ā<sub>*x*</sub> 를 넣고, 계산기수는 1.3절의 적용해지율을 넣은 것을 쓴다. 순보험료 · 기준연납순보험료 · 영업보험료 · *P<sub>β</sub>* 모두 같은 Ā<sub>*x*</sub> 를 쓴다.

**라. 성질**

- *w* = 0 이면 CSV = 0 이고 계산기수도 표준형과 같으므로 **보험료가 표준형과 완전히 같다**.
- 해지자에게 표준형 환급금의 *w<sup>r</sup>* 만 지급하므로 남는 (1 − *w<sup>r</sup>*) 만큼 책임준비금을 덜 쌓아도 되어 보험료가 내려간다. 인하율은 입력값이 아니라 산출 결과다.
- 납입 완료 후에는 *w* = 0 이므로 **저해지형 책임준비금이 표준형과 정확히 같아진다**(3.4절). 낸 보험료는 적었으므로 환급률은 표준형보다 높다.

*(코드: `lib/engine/compute.ts`, `lib/engine/plan.ts`)*

### 2.6. 특약

특약은 주계약과 같은 사업비 구조·납입기간·이율을 쓰고, 보험기간은 100세 만기로 한다. 특약마다 소멸사유 탈퇴율 *q*<sup>exit</sup> 와 급부 발생률 *q*<sup>event</sup> 를 두어 2.1절의 계산기수를 만든다(납입면제·해지율은 적용하지 않는다).

| 특약 | 급부 | *q*<sup>exit</sup> | *q*<sup>event</sup> | 면책 |
|---|---|---|---|---|
| 암진단특약 | 진단 시 정액 | 사망률 + 암발생률 | 암발생률 | 3/4 |
| 암수술특약 | 수술 시 정액 | 사망률 + 암발생률 | 암발생률 × 0.8 *(임시)* | 3/4 |
| 암입원특약 | 입원 1일당 | 사망률 | 암입원율 × 365일 | 3/4 |
| 뇌출혈진단특약 | 진단 시 정액 | 사망률 × 1.35 *(임시)* | 사망률 × 0.35 *(임시)* | 없음 |
| 급성심근경색증진단특약 | 진단 시 정액 | 사망률 × 1.30 *(임시)* | 사망률 × 0.30 *(임시)* | 없음 |
| 입원특약 | 입원 1일당 | 사망률 | min(30, 1 + 800 × 사망률)일 *(임시)* | 없음 |

*(임시)* 표시는 회사 요율을 받지 못해 사망률·암발생률에 계수를 곱한 값이다. 회사 위험률로 교체하면 그대로 반영된다. 암발생률과 암입원율은 제공받은 실제 값이다. *(코드: `lib/riders.ts`, `lib/engine/riders.ts`)*

특약의 급부는 정액이므로 *S<sub>t</sub>* = 1 (첫해만 면책계수)로 두고 2.3~2.4절을 그대로 적용한다. 특약 보험료는 기준금액 10만원당 보험료 × (보장금액/100,000)으로 하고 주계약 보험료에 더한다.

## 3. 책임준비금의 계산에 관한 사항

### 3.1. 적용기초율 보험료적립금(연말)

*P<sub>β</sub>* = ( PVB + CSV<sub>0</sub> + *β′* · ( *N<sub>x+m</sub>* − *N<sub>x+n</sub>* ) ) / ( *N′<sub>x</sub>* − *N′<sub>x+m</sub>* )

<sub>*t*</sub>*V<sub>x</sub>* = [ Σ<sub>*u* ≥ *t*</sub> *S*<sup>산출</sup><sub>*u*</sub> · *C<sub>x+u</sub>* + Σ<sub>*u* > *t*</sub> *C<sub>u</sub>* · *D<sub>x+u</sub>* + CSV<sub>*t*</sub> + *β′* · ( *N<sub>x+max(t,m)</sub>* − *N<sub>x+n</sub>* ) − *P<sub>β</sub>* · ( *N′<sub>x+t</sub>* − *N′<sub>x+m</sub>* ) · [*t* ≤ *m*] ] / *D<sub>x+t</sub>*

순보식에 납입 후 유지비 *β′* 를 더한 형태다. 앞으로 줄 급부(사망·생존·해지)의 현가에서 앞으로 받을 순보험료의 현가를 뺀다. *D<sub>x+t</sub>* ≤ 0 이면 0으로 한다.

CSV 항은 저해지·무해지환급형에만 있고, 표준형은 0이다. *(코드: `lib/engine/reserve.ts`)*

### 3.2. 표준기초율 보험료적립금

표준이율과 표준위험률을 적용하여 3.1절과 같은 식으로 계산한다.

### 3.3. 회계연도말 보험료적립금

적용기초율 보험료적립금과 표준기초율 보험료적립금 중 **큰 금액**으로 한다.

### 3.4. 저해지·무해지환급형의 성질

납입기간 완료 후(*t* ≥ *m*)에는 적용해지율이 0이고 CSV<sub>*t*</sub> = 0 이며 보험료 항도 없으므로

<sub>*t*</sub>*V*<sup>저해지</sup><sub>*x*</sub> = <sub>*t*</sub>*V*<sup>표준형</sup><sub>*x*</sub>   (*t* ≥ *m*)

가 정확히 성립한다(*l* 의 비가 *t* ≥ *m* 구간에서 상수이므로 급부 현가와 *D* 가 같은 비로 줄어든다). 납입기간 중에는 해지자에게 덜 주는 만큼 <sub>*t*</sub>*V*<sup>저해지</sup> < <sub>*t*</sub>*V*<sup>표준형</sup> 이다.

### 3.5. 미경과 보험료적립금

없음. 연중 보간은 하지 않고 연말 기준으로만 산출한다.

## 4. 해지환급금의 계산에 관한 사항

### 4.1. 해약공제

*k*<sub>7</sub> = min( *m*, 7 )

해약공제<sub>*t*</sub> = *α*<sup>공제</sup> · max( *k*<sub>7</sub> − *t*, 0 ) / *k*<sub>7</sub>

*α*<sup>공제</sup> = min( 적용기초율 신계약비 *α*, 표준기초율 신계약비 *α*<sup>std</sup> )   (2.4절, 10만원당 반올림 후 비교)

납입기간과 7년 중 짧은 기간에 걸쳐 매년 균등하게 줄어들고, 그 뒤에는 0이 된다.

### 4.2. 1종 표준형

<sub>*t*</sub>*W*<sup>표준형</sup><sub>*x*</sub> = max( <sub>*t*</sub>*V<sub>x</sub>* − 해약공제<sub>*t*</sub>, 0 )

가입금액 기준 원 단위로 반올림한다. *(코드: `lib/engine/surrender.ts`)*

### 4.3. 2종 저해지환급형 · 3종 무해지환급형

**가. 보험료 납입기간 중**

<sub>*t*</sub>*W<sub>x</sub>* = *w<sup>r</sup>* × <sub>*t*</sub>*W*<sup>표준형</sup><sub>*x*</sub>   (2종 *w<sup>r</sup>* = 70%, 3종 *w<sup>r</sup>* = 0%)

**나. 보험료 납입기간 완료 후**

<sub>*t*</sub>*W<sub>x</sub>* = <sub>*t*</sub>*W*<sup>표준형</sup><sub>*x*</sub>

3.4절에 따라 이 시점의 책임준비금이 표준형과 같으므로 환급금도 같다.

### 4.4. 환급률

환급률<sub>*t*</sub> = <sub>*t*</sub>*W<sub>x</sub>* / 납입누계<sub>*t*</sub>,  납입누계<sub>*t*</sub> = min( *t*, *m* ) × *mm* × *G*

저해지·무해지환급형은 인하된 영업보험료로 납입누계를 계산하므로, 납입 완료 시점의 환급률이 표준형보다 높게 나온다.

## 5. 보험가입금액 등을 변경할 때의 계산에 관한 사항

### 5.1. 재설계(보장 스케줄의 변경)

기존 계약을 해지하지 않고, 그 시점의 **이월 금액 *K*** 와 **앞으로 낼 보험료 *G*** 로 새 보장 스케줄을 사는 것으로 본다.

| 유형 | 이월 금액 *K* |
|---|---|
| 계약 지속·감액 | 그 시점의 책임준비금 |
| 납입 중단 | 그 시점의 해지환급금 |

재설계 계약에는 **신계약비를 부과하지 않는다**(*α<sub>S</sub>* = *α<sub>P</sub>* = 0, 3이원형은 *α* = 0).

*π* = PVB / *D<sub>x′</sub>*  (도달연령 *x′* 에서 시작하는 새 스케줄의 1단위 완납 순보험료 현가)

*S*<sub>0</sub><sup>이월</sup> = *K* / *π*,  *S*<sub>0</sub><sup>보험료</sup> = *G* / *G*<sub>1단위</sub>,  *S*<sub>0</sub> = *S*<sub>0</sub><sup>이월</sup> + *S*<sub>0</sub><sup>보험료</sup>

준비금은 보험료 분담 비율 *f* = *S*<sub>0</sub><sup>보험료</sup> / *S*<sub>0</sub> 를 순보험료 항에 곱한 전향식으로 구한다. *(코드: `lib/engine/redesign.ts`)*

### 5.2. 재설계 판정 규칙

| 코드 | 규칙 |
|---|---|
| R01 | 새 보장의 현가(기존 기초율) ≤ 이월 금액 + 앞으로 낼 순보험료의 현가(기존 기초율) |
| R02 | 새 스케줄의 *모양*(상대 배수)이 5년간 기존보다 높지 않을 것 |
| R03 | 기존 계약의 납입기간·보장기간을 넘지 않을 것 |

R01 · R02는 부록 B(원 규정)와 정의가 다르다. 재설계에는 신계약비를 다시 부과하지 않으므로, 같은 보험료로도 보장이 5~15% 올라가는 것이 정상이기 때문이다. *(코드: `lib/redesign.ts` `checkRules`)*

### 5.3. 보험가입금액의 감액

감액 부분은 해지된 것으로 보고 다음 금액을 지급한다.

지급액 = <sub>*t*</sub>*W<sub>x</sub>* · ( *S* − *S*′ ) / *S*

*S* : 당초 보험가입금액, *S*′ : 감액 후 보험가입금액.

## 7. 일반 상품의 산출(상품 만들기)

설계형이 아닌 보통 상품은 담보(coverage)마다 위험률과 조건을 받아 **담보 하나하나를 독립된 소형 상품으로 산출하고 마지막에 합친다**(원보사 산출방법서의 담보별 산출과 같다). 산식은 1~4절과 동일하다. *(코드: `lib/engine/plan.ts`, 화면 `/builder`)*

### 7.1. 담보별 입력

| 입력 | 내용 |
|---|---|
| 급부 유형 | 진단형 · 사망형 · 일당형 · 생존형(7.2절) |
| 위험률 | 연령별 급부 발생률 *q*<sup>event</sup> 와 탈퇴율 *q*<sup>exit</sup> |
| 보장금액 | 담보별. 일당형은 1일당 금액 |
| 보장 종료 연령 | 담보마다 다를 수 있다 |
| 면책기간 | 개월 수 → 첫해 급부 배율 |
| 보험금 증액·감액 | 연령 구간별 배수 *S<sub>t</sub>* |

계약 단위 입력은 가입나이·성별·보험기간·납입기간·납입주기·예정이율·표준이율·납입면제·저해지/무해지(환급률·해지율)·사업비다.

### 7.2. 급부 유형

| 유형 | *q*<sup>event</sup> | *q*<sup>exit</sup> | 급부 |
|---|---|---|---|
| 진단형 | 발생률 | 사망률 + 발생률 | *S<sub>t</sub>* · *C<sub>x+t</sub>* (발생 후 그 담보 소멸) |
| 사망형 | = *q*<sup>exit</sup> | 사망률 | *S<sub>t</sub>* · *C<sub>x+t</sub>* |
| 일당형 | 연간 기대 지급일수 | 사망률 | *S<sub>t</sub>* · *C<sub>x+t</sub>* (반복 지급이라 소멸하지 않음) |
| 생존형 | — | 사망률 | *C<sub>t</sub>* · *D<sub>x+t</sub>* (정한 시점 생존 시 지급) |

### 7.3. 위험률의 연령 보간

입력한 연령 사이의 빈 나이는 **바로 앞 나이 값을 그대로 이어 쓴다**(첫 나이 앞은 첫 값, 마지막 나이 뒤는 마지막 값). 위험률 표가 보험기간을 덮지 못하면 화면에 경고를 띄운다. *(코드: `lib/plan-rates.ts` `toAgeArray`)*

### 7.4. 합산

- 보험료 = Σ 담보별 (10만원당 보험료 × 보장금액/100,000)
- 책임준비금·해약공제·해지환급금 = Σ 담보별 값
- 납입누계 = min(*t*, *m*) × *mm* × 합계 영업보험료

담보가 하나이고 급부 = 탈퇴(사망보장)인 경우 설계형 산출과 10만원당 보험료·준비금·환급금·환급률이 **완전히 일치**한다(부록 B).

앱에서 내려받는 검산 워크북은 계산기수·보험료·준비금·환급금·특약·저해지 시트가 전부 셀 수식이며, 엔진 값을 캐시로 나란히 담는다. HyperFormula로 전체 재계산하여 표준형 2,514개 · 저해지 4,098개 · 무해지(암) 3,528개 수식이 모두 엔진 값과 일치함을 확인하였다.
