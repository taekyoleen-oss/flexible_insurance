# 1. 위험률 — 뇌출혈·급성심근경색증 실제 발생률

## 1.1. 입력 자료

| 항목 | 내용 |
|---|---|
| 원본 | `뇌출혈 급성심근경색증발생률.xlsx` (사용자 제공) |
| 저장 위치 | `docs/rates/뇌출혈_급성심근경색증_발생률.xlsx` |
| 구조 | 시트 한 장에 표 두 개가 나란히. A~C열 = 연령·뇌출혈 남·여, E~G열 = 연령·급성심근경색증 남·여 |
| 연령 범위 | 뇌출혈 0~84세(85행) · 급성심근경색증 0~79세(80행) |

## 1.2. 변환 절차

```
docs/rates/뇌출혈_급성심근경색증_발생률.xlsx
   ↓ node scripts/build-ci-rates.mjs      (SheetJS. 연령이 0부터 끊김 없이 이어지는지 검사)
lib/engine/data/rates-ci.json             { meta, stroke: {M,F}, ami: {M,F} }
   ↓
lib/riders.ts (특약)  ·  lib/plan-rates.ts (설계 화면 프리셋)
```

표 끝(뇌출혈 84세 · AMI 79세) 뒤의 나이는 **마지막 값을 이어 쓴다**. 이 규칙을 테스트로 고정했다.

## 1.3. 실린 값 (발췌)

| 연령 | 뇌출혈 남 | 뇌출혈 여 | 급성심근경색증 남 | 급성심근경색증 여 |
|---|---|---|---|---|
| 0 | 0.000197 | 0 | 0 | 0 |
| 20 | 0.000025 | 0.000026 | 0.000022 | 0.000006 |
| 30 | 0.000058 | 0.000114 | 0.000117 | 0.000027 |
| 40 | 0.000254 | 0.000601 | 0.000488 | 0.000122 |
| 50 | 0.000674 | 0.000843 | 0.001445 | 0.000460 |
| 60 | 0.001137 | 0.001537 | 0.002989 | 0.001394 |
| 70 | 0.001789 | 0.002188 | 0.004483 | 0.002869 |
| 79 | 0.002978 | 0.003730 | 0.008046 | 0.006446 |
| 84 | 0.004064 | 0.005564 | (79세 값 유지) | (79세 값 유지) |

> 원본 표 확인 결과 **급성심근경색증은 78·79세에서 값이 꺾인다**(남 0.008335 → 0.008315 → 0.008046).
> 원본을 고치지 않고 그대로 실었고, 테스트에서도 "마지막 두 살은 꺾인다"를 명시적으로 고정했다.

## 1.4. 산출 모형에 붙인 방식

진단형 담보이므로 **한 번 지급하면 그 담보가 소멸**한다. 따라서

```
탈퇴율 q = 경험사망률 + 해당 질병 발생률
급부 발생률 g = 해당 질병 발생률
```

바뀐 코드(`lib/riders.ts`):

| | 전 | 후 |
|---|---|---|
| 뇌출혈 탈퇴 | 사망률 × 1.35 | 사망률 + 뇌출혈 발생률 |
| 뇌출혈 급부 | 사망률 × 0.35 *(임시)* | 뇌출혈 발생률 *(제공 자료)* |
| AMI 탈퇴 | 사망률 × 1.30 | 사망률 + AMI 발생률 |
| AMI 급부 | 사망률 × 0.30 *(임시)* | 급성심근경색증 발생률 *(제공 자료)* |

## 1.5. 보험료 영향 (실측)

40세, 100세 만기, 20년납, 월납, 가입금액 10만원당 월보험료(원):

| 담보 | 성별 | 임시 계수(전) | 실제 발생률(후) | 변동 |
|---|---|---|---|---|
| 뇌출혈진단 | 남 | 87 | **44** | −49.4% |
| 뇌출혈진단 | 여 | 77 | **56** | −27.3% |
| 급성심근경색증진단 | 남 | 80 | **69** | −13.8% |
| 급성심근경색증진단 | 여 | 71 | **60** | −15.5% |

임시 계수(사망률 × 0.35 / 0.30)가 실제 발생률보다 컸음이 확인된다. 특히 뇌출혈 남자는 절반 수준으로 내려간다.

## 1.6. 추가한 위험률 프리셋

| id | 이름 | 유형 | 40세 남 | 60세 남 | 근거 |
|---|---|---|---|---|---|

| `twoMajor` | 2대질병 (뇌출혈 + AMI) | 최초발생 | 0.000742 | 0.004126 | 두 발생률의 합 |
| `threeMajor` | 3대질병 (암 + 뇌출혈 + AMI) | 최초발생 | 0.003312 | 0.013056 | 세 발생률의 합 |

### "못 찾음"에 대한 판단

- **납입기간(7건 전부)** — 산출방법서에는 납입기간 값이 없는 것이 정상이다. `5년납/10년납/20년납` 같은

- **사업비(4·5·7)** — 4·5는 PDF 표가 병합 셀 때문에 머리글만 남고 숫자가 흩어졌다.
  7은 사업비가 「별첨 2. 보험료 분석보고서」로 빠져 **이 문서 안에 없다**.
- **교보CI종신 이율** — 2단 편집이라 "3. 예정이율에 관한 사항"과 "연 4.0% 복리"가 서로 먼 칸으로 흩어졌다.
  규칙으로 잇지 못해 **확신도 low(= 기본 미적용)** 로 제안만 한다. 상품명도 같은 이유로 파일명을 쓴다.

| 지급형태 | 남은 보험료를 **매월지급액 × 지급약정기간(월)** 로 대납 |
| 탈퇴율 | 후유장해발생률(80%이상, 상해·질병) + 암발생률 + 뇌졸중발생률 + 급성심근경색증발생률의 **합** |
| 적용이율 | 3.25% (최저보증 1.0%) |
| 예시 계약 | 20년만기 20년납 · 손해조사비 매년 영업보험료의 1% |
| 책임준비금 | 적용기초율 기준과 표준기초율(표준이율의 125%) 기준 중 **큰 값** |

일시금 환산식:

```
[ 납입방법별 순보험료 × k′
  − { 보험년도 연말 순보험료식 보험료적립금 ÷ (1 + 적용이율)
      − 보험년도 연시 순보험료식 보험료적립금 } ] ÷ 12
k′ = 연납 1 · 6개월납 2 · 3개월납 4 · 월납 12
```

## 3.3. 앱에 붙인 방식

이 앱은 **납입자 집단 l′** 로 납입면제를 다룬다.

```
l′_{x+t+1} = l′_{x+t} · ( 1 − q − f − w + ( q·f + q·w + f·w )/2 )_{x+t}
```

`f` 가 이 특약의 지급사유 발생률이다. `f` 가 크면 납입자가 빨리 줄어 `N′` 가 작아지고
`P = PVB / N*` 가 올라간다 — 면제해 주는 값이 보험료에 얹히는 것이며, 위 일시금을 따로 계산하는 방식과 뜻이 같다.

붙이는 순서:

1. **M04 위험률 표**에서 프리셋 "납입면제 발생률 (고도후유장해 + 3대질병)" 을 열로 추가 (납입면제 체크 자동)
2. **M05 납입면제** 단계를 "적용"으로 (탭마다 주계약에서 상속, 특약만 끌 수도 있음)
3. 납입면제로 표시한 열이 여럿이면 **합산**해 `f` 로 쓴다

레시피 **"납입면제(보험료납입지원) 적용 3대질병"** 을 고르면 1~2가 이미 되어 있다.

### 위험률 대체와 그 영향

| 방법서 항목 | 이 앱이 쓰는 값 | 차이 |
|---|---|---|
| 후유장해발생률(80% 이상) | 제7회 경험생명표 장해 **50% 이상** 발생률 | **더 넓다** → 보험료가 조금 크게 나온다 |
| 암발생률 | 생명장기제2024-112호 무배당 예정 암발생률 | 동일 수준 |
| 뇌졸중발생률 | 제공받은 **뇌출혈** 발생률 | 뇌졸중 ⊃ 뇌출혈이라 조금 좁다 |
| 급성심근경색증발생률 | 제공받은 급성심근경색증 발생률 | 동일 |

## 3.4. 넣지 않은 것 (의도적)

- **특약 자체의 보험료** (일시금을 급부로 보는 독립 담보 산출). 보장금액이 "그 시점의 남은 보험료"라
  주계약 보험료와 서로를 참조하는 순환이 생긴다. 필요해지면 `computePlan` 을 두 번 돌려 풀면 된다.
- 1급·2급·3급 장해 등급별 지급률 구분 (합산 하나로 본다).

정리 문서: `docs/납입면제특약_정리.md`

표가 전혀 나오지 않아 사업비가 왕복하지 못했다.
