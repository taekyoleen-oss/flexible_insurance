3. 계산기수

생존자 수

lx = l′x = 100,000
lx+t+1 = lx+t · ( 1 − qx+t − wx+t + qx+t·wx+t/2 )
l′x+t+1 = l′x+t · ( 1 − qx+t − fx+t − wx+t + ( q·f + q·w + f·w )x+t/2 )
q는 탈퇴율(그 담보가 소멸하는 사유 전부), g는 급부 발생률이다. 사망보장은 둘이 같고, 진단형은 q = 사망률 + 발생률, g = 발생률로 갈라진다.

계산기수

Dx+t = lx+t·vt    D′x+t = l′x+t·vt
Cx+t = lx+t·gx+t·( 1 − wx+t/2 )·vt+½    Wx+t = lx+t·wx+t·vt+½
Nx+t = Σu≥t Dx+u    N′x+t = Σu≥t D′x+u
q·(1−w/2) + w = q + w − q·w/2 이므로 급부 탈퇴와 해지 탈퇴의 합이 lx+t − lx+t+1과 정확히 일치한다.

4. 보험료의 계산

급부 현가와 납입기수

PVB = Σt=0n−1 St·Cx+t + Σt=0n Ct·Dx+t
N* = mm · [ ( N′x − N′x+m ) − ( mm−1 )/( 2·mm )·( D′x − D′x+m ) ]

순보험료·기준연납순보험료

P = PVB / N*        Pbase = PVB / ( N′x − N′x+min(n,20) )

영업보험료

G = [ P + ( αS + αP·Pbase )·D′x/N* + βS/mm + β′·( Nx+m − Nx+n )/N* ] / ( 1 − βG − γ )
보장기간 n이 20년보다 짧으면 αP는 αP × n/20으로 줄인다. 10만원당 보험료에서 한 번만 반올림하고, 담보 보험료 = 10만원당 보험료 × (보장금액 ÷ 100,000)으로 한다.

5. 책임준비금의 계산

연말 책임준비금

Pβ = ( PVB + CSV0 + β′·( Nx+m − Nx+n ) ) / ( N′x − N′x+m )
Vt = [ Σu≥t Su·Cx+u + Σu>t Cu·Dx+u + CSVt + β′·( Nx+max(t,m) − Nx+n ) − Pβ·( N′x+t − N′x+m )·[t≤m] ] / Dx+t
순보식에 납입 후 유지비 β′를 더한 형태. 표준준비금은 표준이율로 같은 식을 계산한다.

6. 해지환급금의 계산

해약공제와 해지환급금

해약공제t = α공제 · max( min(m,7) − t, 0 ) / min(m,7)        α공제 = min( α, αstd )
α = αS + αP · round₅( Pbase )    (영업보험료 G 에는 반올림 전 Pbase 를 쓴다)
W표준t = max( Vt − 해약공제t, 0 )

환급률

환급률t = Wt / 납입누계t,   납입누계t = min(t, m) × mm × G

7. 책임준비금 관련 사항

회계연도말 보험료적립금은 적용기초율 적립금과 표준기초율 적립금 중 큰 금액으로 한다.
연중 보간은 하지 않고 연말 기준으로 산출한다.

8. 해지환급금 관련 사항

해약공제는 납입기간과 7년 중 짧은 기간에 걸쳐 매년 균등하게 줄어든다.
해약공제 기준 신계약비는 적용기초율과 표준기초율로 구한 신계약비 중 작은 쪽으로 한다.
