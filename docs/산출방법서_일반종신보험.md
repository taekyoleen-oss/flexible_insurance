## 3. 계산기수

유지자수·납입자수 — 사망·80% 이상 장해

```
q_x : 제7회 경험생명표 사망률 q
k_x : 80% 이상 장해율

l_x = l′_x = 100,000
유지자수  l_{x+t+1} = l_{x+t} × ( 1 − q_{x+t} − k_{x+t} + q_{x+t}·k_{x+t}/2 )
납입자수  l′_{x+t+1} = l′_{x+t} × ( 1 − q_{x+t} − k_{x+t} + q_{x+t}·k_{x+t}/2 )        → l′_{x+t} = l_{x+t}
급부 발생자  C_{x+t} = ( l_{x+t} − l_{x+t+1} )·v^{t+½}
```

> 사망·80% 이상 장해 모두 같은 보험금을 지급하므로 탈퇴자 전부가 급부 대상이다. 납입자수 l′ 는 탈퇴 사유로 유지자수와 똑같이 줄어든다 — 별도의 납입면제율을 곱하지 않는다.

계산기수

```
D_{x+t} = l_{x+t}·v^t    D′_{x+t} = l′_{x+t}·v^t
C_{x+t} = l_{x+t}·g_{x+t}·( 1 − w_{x+t}/2 )·v^{t+½}    W_{x+t} = l_{x+t}·w_{x+t}·v^{t+½}
N_{x+t} = Σ_{u≥t} D_{x+u}    N′_{x+t} = Σ_{u≥t} D′_{x+u}
```

> g 는 위 담보별 식의 급부 발생률이다. Q·(1−w/2) + w = Q + w − Q·w/2 이므로 급부·해지 탈퇴의 합이 l_{x+t} − l_{x+t+1} 과 정확히 일치한다.

## 4. 보험료의 계산

급부 현가와 납입기수

```
PVB = Σ_{t=0}^{n−1} S_t·C_{x+t} + Σ_{t=0}^{n} C_t·D_{x+t}
N* = mm · [ ( N′_x − N′_{x+m} ) − ( mm−1 )/( 2·mm )·( D′_x − D′_{x+m} ) ]
```

순보험료·기준연납순보험료

```
P = PVB / N*        P_base = PVB / ( N′_x − N′_{x+min(n,20)} )
```

영업보험료

```
G = [ P + ( α_S + α_P·P_base )·D′_x/N* + β_S/mm + β′·( N_{x+m} − N_{x+n} )/N* ] / ( 1 − β_G − γ )
```

> 보장기간 n이 20년보다 짧으면 α_P는 α_P × n/20으로 줄인다. 10만원당 보험료에서 한 번만 반올림하고, 담보 보험료 = 10만원당 보험료 × (보장금액 ÷ 100,000)으로 한다.

## 5. 책임준비금의 계산

연말 책임준비금

```
P_β = ( PVB + CSV_0 + β′·( N_{x+m} − N_{x+n} ) ) / ( N′_x − N′_{x+m} )
V_t = [ Σ_{u≥t} S_u·C_{x+u} + Σ_{u>t} C_u·D_{x+u} + CSV_t + β′·( N_{x+max(t,m)} − N_{x+n} ) − P_β·( N′_{x+t} − N′_{x+m} )·[t≤m] ] / D_{x+t}
```

> 순보식에 납입 후 유지비 β′를 더한 형태. 표준준비금은 표준이율로 같은 식을 계산한다.

## 6. 해지환급금의 계산

해약공제와 해지환급금

```
해약공제_t = α^공제 · max( min(m,7) − t, 0 ) / min(m,7)        α^공제 = min( α, α^std )
α = α_S + α_P · round₅( P_base )    (영업보험료 G 에는 반올림 전 P_base 를 쓴다)
W^표준_t = max( V_t − 해약공제_t, 0 )
```

환급률

```
환급률_t = W_t / 납입누계_t,   납입누계_t = min(t, m) × mm × G
```

## 7. 책임준비금 관련 사항

> 회계연도말 보험료적립금은 적용기초율 적립금과 표준기초율 적립금 중 큰 금액으로 한다.

> 연중 보간은 하지 않고 연말 기준으로 산출한다.

## 8. 해지환급금 관련 사항

> 해약공제는 납입기간과 7년 중 짧은 기간에 걸쳐 매년 균등하게 줄어든다.

> 해약공제 기준 신계약비는 적용기초율과 표준기초율로 구한 신계약비 중 작은 쪽으로 한다.
