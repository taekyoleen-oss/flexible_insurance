# 설계형 종신보험 (flexible whole life)

보험사가 정한 보험금 구조에 계약자가 보험료를 맞추던 방식을 뒤집어, 계약자가 자기 상황(자녀·부채·은퇴·단체보험·상속)에 맞춰 연령별 보험금을 직접 설계하고 보험료·준비금·해약환급금을 즉시 확인하는 종신보험의 엔진과 Next.js 앱. 프리셋은 이론·수식으로 산정한 필요액 곡선을 설계 규칙(초기 5년 고정, 매년 최대 10%, 70세 이후 증액 불가, 3배 상한, 20% 하한)에 맞춘 출발점이고 최종 모양은 계약자가 그래프에서 그린다.

- 상품: 종신보험(사망보험금, 종신)과 암보험(암진단보험금, 100세 만기, 사망 시 책임준비금 지급). 시작 화면에서 고르며 설계 화면은 공통. 암보험은 암발생률 단일탈퇴(`rates-cancer.json`)·면책 3/4·가정 세트 `cancer-2026`
- 특약 6종(암진단·암수술·암입원·뇌출혈·급성심근경색·입원): 정액, 100세 만기(사망 담보 외 공통)·납입은 주계약 준용, 체크·금액 → 월 보험료와 최종 합계. 암발생률(2024-112호)·암입원율은 제공 자료(`docs/rates`), 나머지는 임시 계수(`lib/riders.ts`)
- 계획서: `docs/tkLeen_설계형종신보험_앱개발계획서.md` (§3.4 엔진 명세, §7 골든값)
- 엔진 구현 계획: `docs/superpowers/plans/2026-09-10-engine.md`

- 산출방법서 변환기 모듈: `lib/methoddoc/README.md` — 다른 앱에 옮기는 법·지원 형식·한계
- 고급 기능 계획: `docs/계획_산출방법서_역입력.md` — 산출방법서 파일을 읽어 `/builder` 입력으로 되돌리는 기능의 단계별 계획(미구현)
- 산출방법서: `docs/산출방법서_설계형보험.md` (+ `.docx`, `.pdf`) — 기초율·보험료·책임준비금·해지환급금·재설계·설계 제약·일반 상품 산출을 산출방법서 형식으로 정리

## 명령

```bash
npm test                        # vitest 골든·규칙 테스트
node scripts/extract-rates.mjs  # 위험률표 재추출 (../Python_Web_like_Excel 워크북 필요)
node scripts/build-formula-doc.mjs  # lib/formulas.json → docs/산출수식_설명.md
node --no-warnings scripts/build-method-doc.mjs  # 산출방법서 .md → .docx / .pdf (pandoc + chromium)
node scripts/copy-pdf-worker.mjs    # pdfjs 워커를 public/ 으로 복사 (prebuild·predev 가 자동 실행)
npm run dev                     # Next.js 개발 서버
```

그래프 편집 규칙: 1칸 = 기준보험금 10%, 직전 변경점이 정한 수준에서 지난 연수만큼 ±, 올리든 내리든 매년 최대 1칸, 프리셋 모양 위에 변화폭을 더함(50세 3칸 ↑ = 47·48·49세 1.1·1.2·1.3), 더블클릭 = 이후 평탄화, 직선 위 변경점은 자동 삭제, 추가 조건(자녀교육·대출상환·정액)은 별도 점선으로 보이다가 결합하면 스케줄에 더해짐, 축하금 = 해당 연령 보험금의 10%(여러 나이를 쉼표로 입력). 기준보험금은 1천만원 단위. 저해지 = 납입기간 중 환급금 30%·보험료 20% 인하.

설계 상태는 localStorage(`fwl:design:v1`)에 자동 저장되고, 보관함(`fwl:designs:v1`)에 이름으로 여러 건을 둘 수 있다. Supabase는 사용하지 않는다(백업·이동은 JSON 파일과 공유 링크).

## 엔진 `lib/engine`

UI 무관 순수 함수. 진입점은 `compute`, `compareAtBudget`, `validate`, `buildPreset`, `needs` (`lib/engine/index.ts`).

| 모듈 | 내용 |
|---|---|
| `commutation` | 이중탈퇴(사망+납입면제) 생존자표·계산기수 |
| `schedule` | 구간 카드 ↔ 연도별 보험금 배수 벡터 |
| `premium` | 급부 현가, 월납 보정 N*, 순·기준연납·영업보험료, 부가보험료 분해 |
| `reserve` / `surrender` | 연말 준비금, 해약공제·환급금·환급률 |
| `compute` | 통합 산출(적용·표준기초, 10만원당 반올림, 사업비 흐름, 저해지: 납입기간 중 환급금 30%·보험료 20% 인하) |
| `presets` / `envelope` | 프리셋 6종(표준 모양 + 조건 반영 시 필요액 곡선), 설계 제약 E01~E08 |
| `finance` | 대출 잔액 B_t, 기대여명 e_x, 상속세, 필요액 곡선 → 규칙 적합 배수(`regularizeShape`) |
| `needs` / `compare` | 니즈·HLV·프리셋 추천, 프리셋별 필요액 곡선(자녀·부채·은퇴·단체·상속세), 같은 예산 3안 비교 |
| `redesign` | 재설계: 이월액이 사는 완납분 + 보험료가 사는 부분으로 기준보험금 역산, 신계약비 없음 |
